Perubahan pada build ini:
  [PERBAIKAN] Portrait bagian bawah terpotong, menu tak terakses:
    - Akar masalah: targetSdk 35 (Android 15) memberlakukan mode
      edge-to-edge, sehingga window digambar di belakang navigation
      bar sistem. Toolbar/menu bawah tertutup nav bar.
    - Opt-out edge-to-edge: setDecorFitsSystemWindows(true) di
      onCreate (API 30+) agar nav bar memesan tempat sendiri dan
      UI bawah selalu terlihat/terakses
    - Modernisasi updateImmersiveMode: pakai WindowInsetsController
      (API 30+) untuk benar-benar menyembunyikan/menampilkan system
      bars (setSystemUiVisibility sudah deprecated/diabaikan di
      API 30+). Immersive aktif = fullscreen, non-immersive = nav
      bar memesan tempat.
